# 圆角轮廓、输入与模糊边界

## 当前范围

第四阶段 4d 统一既有矩形/统一圆角矩形的几何规则。公用实现为
`prism/contracts/rounded_region.hpp`，只依赖标准 C++ 与纯契约，无 Skia/Wayland/WM 依赖。
本轮没有新增连接颈、任意 Path、非对称圆角或跨 surface 协议。

## 一套几何，多种用途

- `NormalizeRoundedRegion` 将半径夹紧到 `[0, min(width,height)/2]`；无效形状归为空。
- `RoundedRegionContains` 使用逻辑坐标；命中右/下边界为开区间。形状包含判断可显式
  使用闭边界，不能把用于外包判断的闭边界选项拿去替代普通命中。
- `RoundedRegionSpan` 返回指定逻辑 y 上的圆角水平区间。
- `RasterizeRoundedIntersection` 生成所有形状交集中的整数逻辑像素中心掩码，合并相邻
  相同跨度行。非法数值拒绝；结果坐标与扫描高度有限制，避免整数转换溢出和无界扫描。

Scene 实时命中与已提交快照命中使用同一个包含判断；RenderTree 发出的背景、裁剪、
边框和阴影使用同一个归一化半径。surface effect 的形状归一化与包含判断也共用该实现。
Wayland 输入 region 与 Scene 的复杂交集输入区域使用同一个栅格化器，不再各自取整。

整数逻辑像素 `(x,y)` 是否加入输入区域，由 `(x+0.5,y+0.5)` 是否在几何形状内决定。
例如 x=0.25、width=20 的矩形覆盖中心为 0.5 到 19.5 的像素，而不是按 ceil(x) 丢掉
第一个像素。设备缩放不改变该逻辑输入坐标约定。

相同跨度的多行合并成一个矩形后再发送 Wayland region；大矩形可以只发一次 add。
这是减少区域指令数，不意味着已经测得帧率提升。区域生成仍按事件/几何变化触发。

## 呈现与输入的边界

Skia 的边缘是抗锯齿覆盖率，输入 region 是二值掩码，两者不能逐个半透明像素完全相等。
验证包含全透明/全覆盖像素与几何中心判定，并单独检查所有整数像素中心的输入一致性。
分数坐标处不可避免的亚像素差异不应误写成输入接受整个外包矩形。

外阴影不属于控件命中和 backdrop 区域；模糊采样可以读取轮廓外的背景，但效果输出
必须限制于请求轮廓。Popup/Menu 开启时，owner 的外点接收区刻意覆盖正文，用于关闭
浮层；这是关闭屏障，不代表圆角外属于菜单命令。两者在输入路由中保持不同语义。

## 模糊协议限制

现有 v1 只支持统一半径圆角矩形。等边界、完全包含、可精确化为矩形的裁剪可发送；
不同圆心/偏移圆角相交得到的非对称轮廓继续明确拒绝，不能扩大为外包矩形。
八个 effect 区域与 8192 逻辑尺寸上限保持不变。

[通用轮廓基础契约](SURFACE_CONTOUR_CONTRACT.md)已提供有界路径准备、几何、payload
与 DisplayList/Skia 接口，4f 已接入 Wayland v2 和 WM 覆盖遮罩，4g 接入 Scene/DSL、
实时/快照命中和输入 region。声明 Contour 时由它覆盖原有 cornerRadius 的形状语义；
混合裁剪直接求规范多边形与解析圆角的像素中心交集，不把圆角转换成近似多边形。
连接颈随锚点/尺寸生成的主题配方仍待后续；不得用装饰三角形冒充完整轮廓。

## 验证入口

- `rounded_region_test`：48 组小数/负坐标与半径组合，分别检查单形状和交集，共 96
  个栅格场景逐像素比较；验证矩形合并、空形状、非法数值与扫描限制。
- `rounded_scene_test`：Scene 实时命中、提交快照、输入掩码、effect 形状与真实 Skia
  raster 像素，对照 0/1/8/超尺寸半径。
- `visual_scene_test`：已有裁剪、surface effect 拒绝与事务回滚回归。

GPU 背景采样和 VNC 实机效果需要后续部署验收；本轮不以 raster 测试代替这些结论。
