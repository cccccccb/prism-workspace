# DSL 视口条件显示

2026-10-05，为已确认的 Concept B 提供通用紧凑布局能力。

所有节点可声明 `minViewportWidth`、`maxViewportWidth`、`minViewportHeight`、
`maxViewportHeight`。使用整个客户端 surface 的逻辑宽高，包含根 padding，不是父容器尺寸。
最小值包含端点，最大值不包含端点；0 表示不设上限。缺省值均为0；值域0..16384。
条件与显式 visible 以及祖先可见性取交集。互相矛盾的区间为空，不自动更换顺序。

```prism
Card(minViewportHeight: 540) { /* 完整内容 */ }
Card(maxViewportHeight: 540) { /* 紧凑内容 */ }
```

由 Scene 所有者按配置尺寸生成不可变布局/输入快照；渲染线程消费同一可见性。
隐藏分支不占布局空间、不绘制、不命中，也不参与键盘焦点遍历。尺寸变化清理过期
悬停/按压/焦点，不延续到新分支。条件不可动画，窗口缩放不触发业务回调或常驻定时器。
显式 binding 可继续控制业务状态，尺寸选择不需要应用读取 WM 信息。

该能力只控制已有节点的呈现，不是资源延迟加载、滚动容器或虚拟列表。
切换布局分支不会自动把输入框焦点、光标或撤销历史转移至另一个节点；编辑器应保持
稳定节点。不能把多份 TextArea 当作响应式状态同步方案。

## 发布兼容

这些属性需要本轮更新后的 Host/Scene；旧 Host 会按未知 DSL 属性拒绝包。
发布时将应用与新 Host 一起构建打包，不单独把新 DSL 覆盖到旧 v21 会话。
