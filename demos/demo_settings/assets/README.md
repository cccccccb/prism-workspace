Material sample thumbnails, authored for the Concept B design using SVG gradients and curves.
Sources: docs/design/prism-concept-b/materials/*.svg.
Rebuild: python3 tools/render-material-previews.py (development librsvg/Cairo only).
The application consumes PNG through the shared Image interface and does not depend on librsvg.
Dark/light examples are selected by the confirmed session palette. They illustrate materials;
they are not live background captures. No screenshot of an entire interface is used as a widget.
